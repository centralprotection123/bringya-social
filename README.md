# bringya-social

Images for BringYa's daily social posts (Facebook, Instagram, TikTok), designed and published automatically.

- `DESIGN.md`: creative and design rules every post follows
- `render.py`: renders a post's HTML to a 1080×1350 JPEG and checks the layout
- `brand/`: official logo and real app screenshots
- `examples/`: approved reference designs
- `posts/`: every published image, by date, plus `log.json` (format, topic, lead colour) so posts don't repeat
